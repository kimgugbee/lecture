RAG 실습 패키지 설치

Python 3.12 기준

LangChain, Chroma, Streamlit 등 RAG 실습에 필요한 패키지를 한 번에 설치합니다.
파이썬 설치 가이드부터 터미널 설정과 패키지 설치까지 먼저 마친 뒤 진행합니다.

1

가상환경의 파이썬 버전 확인

VS Code 터미널에서 입력 줄 앞에 (.venv)가 붙어 있는지 확인합니다.
그다음 아래 명령어를 입력합니다.

python --version

Python 3.12.10처럼 3.12로 시작하면 다음 단계로 넘어갑니다.

3.13 이상이 나오면 설치 중에 오류가 납니다.
최신 파이썬용 설치 파일이 아직 없는 패키지가 있기 때문입니다.
아래 문제 해결의 Failed to build 'zstandard' 항목대로 3.12 가상환경을 다시 만듭니다.
2

pip 최신 버전으로 업데이트

오래된 pip는 설치 파일을 제대로 찾지 못할 수 있으므로 먼저 업데이트합니다.

python -m pip install --upgrade pip

Successfully installed pip 또는 Requirement already satisfied가 나오면 됩니다.

3

RAG 패키지 설치

아래 명령어를 한 줄 그대로 복사해 붙여 넣고 Enter를 누릅니다.
패키지가 많아 몇 분 걸릴 수 있습니다.

pip install langchain langchain-google-genai langchain-chroma langchain-community pypdf==6.17.0 streamlit python-dotenv ipykernel
패키지용도
langchainRAG 파이프라인 구성
langchain-google-genaiGemini 모델 연결
langchain-chromaChroma 벡터 DB 연결
langchain-community문서 로더 등 부가 기능
pypdf==6.17.0PDF 문서 읽기 (버전 고정)
streamlit웹 화면 만들기
python-dotenv.env 파일의 API 키 불러오기
ipykernel주피터 노트북에서 코드 실행

마지막 줄에 Successfully installed가 나오면 설치가 끝난 것입니다.

4

설치 확인

아래 명령어를 입력합니다. 패키지를 실제로 불러와 보는 명령어입니다.

python -c "import langchain, langchain_chroma, langchain_google_genai, pypdf, streamlit, dotenv; print('OK')"

OK가 출력되면 완료입니다.오류가 나오면 아래 문제 해결을 확인하세요.

문제 해결

ERROR: Failed to build 'zstandard' when getting requirements to build wheel

가상환경의 파이썬이 3.13 이상처럼 너무 최신인 경우입니다.
그 버전용 설치 파일이 없어 직접 빌드하려다 실패한 것입니다. 3.12로 가상환경을 다시 만듭니다.

  1. 아래 명령어로 설치된 파이썬 목록을 봅니다. 3.12가 없으면 파이썬 설치 가이드대로 3.12.10을 설치합니다.
py --list
  1. VS Code 왼쪽 Explorer에서 .venv 폴더를 마우스 오른쪽 버튼으로 클릭하고 Delete로 지웁니다.
  2. 터미널을 휴지통 아이콘으로 닫고 새로 연 뒤, 아래 명령어로 3.12 가상환경을 만듭니다.
py -3.12 -m venv .venv
  1. 가상환경을 켜고 1단계부터 다시 진행합니다.
.venv\Scripts\activate

노트북을 쓰고 있었다면 오른쪽 위 커널도 새 .venv (3.12.10)으로 다시 선택합니다.

No such file or directory 또는 경로가 너무 길다는 오류가 납니다

Windows의 260자 경로 길이 제한에 걸린 경우입니다.
파이썬 설치 마지막 화면에서 Disable path length limit을 누르지 않았다면, 설치 파일을 다시 실행해 Modify → Next → Install로 끝까지 진행한 뒤 마지막 화면에서 누릅니다.

작업 폴더를 D:\study처럼 짧은 경로에 두는 것도 도움이 됩니다.

입력 줄 앞에 (.venv)가 없습니다

터미널을 닫고 새로 엽니다.
그래도 없으면 아래 명령어로 가상환경을 직접 켭니다.

.venv\Scripts\activate
노트북에서 import하면 ModuleNotFoundError가 납니다

노트북 오른쪽 위에 .venv가 선택되어 있는지 확인합니다.
맞다면 상단의 Restart를 클릭한 뒤 다시 실행합니다.
