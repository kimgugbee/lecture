Gemini API 키 발급

Google AI Studio에서 프로젝트를 만들고 Gemini API 키를 발급받습니다.
구글 계정으로 로그인한 상태에서 진행합니다.

1

새 프로젝트 만들기

사진의 번호 순서대로 진행합니다.

  1. 주소창에 aistudio.google.com/projects를 입력해 접속합니다.
  2. 왼쪽 메뉴에서 프로젝트를 클릭합니다.
  3. 오른쪽 위 새 프로젝트 만들기를 클릭합니다.

Google AI Studio 프로젝트 페이지 열기

2

프로젝트 이름 설정

  1. 프로젝트 이름을 입력합니다.
    예시에서는 prj01을 사용합니다.
  2. 프로젝트 만들기를 클릭합니다.
3

API 키 만들기

프로젝트를 만들면 새 키 만들기 창이 자동으로 열립니다.
창이 열리지 않으면 왼쪽 메뉴에서 API 키를 클릭하고, 오른쪽 위 API 키 만들기를 클릭합니다.

창이 열리면 아래 순서로 진행합니다.

  1. 키 이름을 입력합니다.
    예시에서는 prj01key를 사용합니다.
  2. 가져온 프로젝트 선택에서 방금 만든 프로젝트를 선택합니다.
  3. 키 만들기를 클릭합니다.
4

프로젝트 확인

왼쪽 메뉴에서 프로젝트를 클릭합니다.
만든 프로젝트의 키 칸에 키 1개가 보이면 클릭합니다.

5

API 키 선택

API 키 화면이 열립니다.
키 칸의 ...으로 시작하는 파란 글자를 클릭합니다.
끝 네 글자는 사람마다 다릅니다.

6

키 복사

API 키 오른쪽의 복사 아이콘이나 아래 키 복사를 클릭합니다.
복사한 키는 메모장 등에 붙여 넣어 보관합니다.

사진의 키 값은 예시입니다.

키를 복사했으면 발급 완료입니다.키는 이 창에서 언제든 다시 복사할 수 있습니다.

키 관리 주의사항

API 키는 비밀번호처럼 다룹니다.
다른 사람이 내 키를 쓰면 내 사용량으로 기록됩니다.
  • 키를 단톡방, 게시판, 과제 제출물에 붙여 넣지 않습니다.
  • 키가 들어 있는 코드나 파일을 GitHub에 올리지 않습니다.
  • 키가 노출됐다면 6단계 창의 키 삭제로 지우고 새로 만듭니다.
