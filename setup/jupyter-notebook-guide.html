주피터 노트북 사용법

VS Code에서 .ipynb 파일을 다룰 때 알아야 할 내용을 정리했습니다.
필요한 항목을 골라서 봐도 됩니다.

단축키 셀 간 메모리 공유 오래된 메모리 삭제 전체 실행과 오류 마크다운 작성법

단축키

셀 실행

많이 쓰는 실행 단축키는 세 가지입니다.
실행한 뒤 커서가 어디로 가는지가 다릅니다.

단축키동작실행 후 위치
Ctrl + Enter실행현재 셀에 그대로 있습니다.
Shift + Enter실행 + 이동아래 셀로 이동합니다.
마지막 셀이면 새 셀을 만듭니다.
Alt + Enter실행 + 이동 + 생성바로 아래에 새 셀을 만들고 이동합니다.

모드 전환

셀에는 내용을 입력하는 편집 모드와 셀 자체를 다루는 명령 모드가 있습니다.

단축키동작
Esc명령 모드로 전환합니다.
Enter편집 모드로 전환합니다.

셀 편집

아래 단축키는 명령 모드에서 사용합니다.

단축키동작
A위에 새 셀을 추가합니다.
B아래에 새 셀을 추가합니다.
D DD를 두 번 눌러 셀을 삭제합니다.
Z방금 한 작업을 되돌립니다.
삭제한 셀도 되살릴 수 있습니다.
M마크다운 셀로 바꿉니다.
Y코드 셀로 바꿉니다.
L줄 번호를 켜거나 끕니다.
먼저 Esc를 누릅니다.
편집 모드에서 누르면 단축키가 아니라 글자가 입력됩니다.

셀 간 메모리 공유

셀은 나뉘어 있어도 메모리는 하나입니다.
모든 셀이 함께 쓰는 칠판이 하나 있다고 생각하면 됩니다.
한 셀에서 만든 변수를 다른 셀에서 그대로 쓸 수 있습니다.

[1]
a = 10
[2]
print(a)
10

실행 순서가 결과를 정합니다

결과는 셀의 위치가 아니라 실행한 순서로 정해집니다.
셀 왼쪽의 번호가 실행 순서입니다.

아래 예시는 두 번째 셀을 먼저 실행한 경우입니다.
마지막에 실행한 a = 10이 칠판에 남아 있어 10이 출력됩니다.

[2]
a = 10
[1]
a = 20
[3]
print(a)
10

지금 메모리에 있는 변수는 상단의 Jupyter Variables를 클릭하면 볼 수 있습니다.

오래된 메모리 삭제

변수는 코드를 실행하는 프로그램인 커널의 메모리에 저장됩니다.
그래서 셀을 지워도 그 셀에서 만든 변수는 메모리에 남아 있습니다.

아래 예시는 price = 1000 셀을 실행한 뒤 삭제한 경우입니다.
코드는 사라졌지만 값은 그대로 출력됩니다.

삭제
price = 1000
[2]
print(price)
1000

지금은 실행되지만, 파일을 다시 열어 처음부터 실행하면 오류가 납니다.

메모리 비우기

상단의 Restart를 클릭하면 커널이 다시 시작되고 메모리가 모두 지워집니다.
다시 실행하면 지워진 변수를 찾지 못해 오류가 납니다.

[1]
print(price)
NameError: name 'price' is not defined
방법지워지는 것
Restart메모리의 모든 변수를 지웁니다.
del a변수 a 하나만 지웁니다.
Clear All Outputs화면의 실행 결과만 지웁니다.
메모리의 변수는 그대로 남습니다.
제출하거나 공유하기 전에 Restart 후 Run All을 실행합니다.
오류 없이 끝까지 실행되면 메모리에 남은 값에 의존하지 않는 코드입니다.

전체 실행과 오류

상단의 Run All은 모든 셀을 위에서부터 차례로 실행합니다.
중간 셀에서 오류가 나면 거기서 멈추고, 아래 셀은 실행되지 않습니다.

[1]
a = 10
print(a)
10
[2]
b = 1 / 0
print(b)
ZeroDivisionError: division by zero
[ ]
print('마지막 셀')
실행되지 않아 번호와 결과가 비어 있습니다.

오류가 난 셀을 고친 뒤 Run All을 다시 클릭합니다.

마크다운 셀에는 코드 대신 제목이나 설명을 적습니다.

결과 보기Ctrl + Enter 또는 Shift + Enter를 누릅니다.
