터미널 설정과 패키지 설치

VS Code의 기본 터미널을 PowerShell 대신 cmd로 바꾸고, pip로 수업에 필요한 패키지를 설치합니다.
VS Code 파이썬 가상환경 설정을 먼저 마친 뒤 진행합니다.

1

기본 터미널을 cmd로 설정

사진의 번호 순서대로 진행합니다.

  1. 왼쪽 아래 톱니바퀴 아이콘을 클릭합니다.
  2. 메뉴에서 Settings를 클릭합니다.
    Ctrl + ,를 눌러도 됩니다.
  3. 검색 칸에 default profile을 입력합니다.
  4. Default Profile: Windows 항목에서 Command Prompt를 선택합니다.
  5. 오른쪽 위 X를 클릭해 설정 창을 닫습니다.

설정은 바로 저장되므로 따로 저장 버튼을 누르지 않습니다.

Linux, Osx 항목이 아니라 Windows 항목을 바꿉니다.
세 항목이 비슷하게 생겼으니 이름 끝을 확인합니다.
2

터미널 열기

오른쪽 위의 패널 아이콘을 클릭합니다.
또는 Ctrl + `를 누릅니다.
`는 숫자 1 왼쪽에 있는 키입니다.

터미널 오른쪽 위에 cmd가 보이면 설정이 적용된 것입니다.

설정 전에 열어 둔 터미널은 PowerShell 그대로입니다.
휴지통 아이콘으로 기존 터미널을 닫고 새로 엽니다.
3

가상환경 확인

입력 줄 맨 앞에 (.venv)가 붙어 있는지 확인합니다.
붙어 있어야 패키지가 가상환경 안에 설치됩니다.

입력 줄 모양상태
(.venv) D:\study>가상환경 사용 중
D:\study>가상환경 아님

(.venv)가 없으면 아래 문제 해결을 확인합니다.

4

패키지 설치

아래 명령어를 입력하고 Enter를 누릅니다.
패키지 이름을 띄어쓰기로 구분하면 여러 개를 한 번에 설치할 수 있습니다.

pip install ipykernel numpy pandas
패키지용도
ipykernel주피터 노트북에서 코드 실행
numpy숫자 배열 계산
pandas표 형태 데이터 처리

마지막 줄에 Successfully installed가 나오면 설치가 끝난 것입니다.

5

설치 확인

아래 명령어로 설치된 패키지 목록을 봅니다.

pip list

목록에 ipykernel, numpy, pandas가 보이면 완료입니다.문제가 있으면 아래 문제 해결을 확인하세요.

패키지는 지금 폴더의 .venv에만 설치됩니다.
새 폴더에서 가상환경을 새로 만들면 다시 설치해야 합니다.

문제 해결

입력 줄 앞에 (.venv)가 없습니다

터미널을 닫고 새로 엽니다.
그래도 없으면 아래 명령어로 가상환경을 직접 켭니다.

.venv\Scripts\activate
'pip'은(는) 내부 또는 외부 명령이 아닙니다

가상환경이 켜져 있지 않거나 파이썬 PATH 설정이 빠진 경우입니다.
먼저 위의 방법으로 (.venv)를 켠 뒤 다시 입력합니다.

노트북에서 import하면 ModuleNotFoundError가 납니다

노트북 오른쪽 위에 .venv가 선택되어 있는지 확인합니다.
맞다면 상단의 Restart를 클릭한 뒤 다시 실행합니다.

터미널이 여전히 PowerShell로 열립니다

1단계의 Default Profile: Windows 값이 Command Prompt인지 다시 확인합니다.
기존 터미널을 휴지통 아이콘으로 모두 닫고 새로 엽니다.
